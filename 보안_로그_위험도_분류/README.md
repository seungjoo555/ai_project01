# 🔐 보안 로그 위험도 분류

> **DAICON 보안 로그 위험도 분류 AI 경진대회를 기반으로 진행한 팀 프로젝트**

보안 로그 데이터를 활용하여 로그의 위험도를 분류하는 머신러닝·딥러닝 프로젝트입니다.

경진대회 데이터를 기반으로 텍스트 전처리, 특징 추출, 분류 모델 학습 및 성능 평가를 수행했습니다. 다양한 로그 마스킹 방법을 적용하여 비식별화 전처리가 분류 성능에 미치는 영향을 비교하고, 여러 딥러닝 모델과 앙상블 기법을 활용하여 분류 성능을 개선하는 과정을 진행했습니다.

보안 로그에는 IP 주소, 날짜, 시간, 포트 번호, 숫자 및 각종 식별 정보가 포함될 수 있습니다. 이러한 값들은 로그의 의미를 파악하는 데 영향을 줄 수 있으므로, 로그의 구조와 의미를 유지하면서 불필요한 가변 정보를 마스킹하는 전처리 방법을 실험했습니다.

프로젝트의 주요 목표는 다음과 같습니다.

* 보안 로그 데이터를 활용한 위험도 분류 모델 학습
* 로그 내 가변적인 정보에 대한 마스킹 전처리
* 마스킹 대상 및 적용 단계에 따른 분류 성능 비교
* TF-IDF 기반 텍스트 특징 추출 및 머신러닝 모델 학습
* 딥러닝 기반 로그 분류 모델 학습
* 학습한 모델과 전처리 객체의 저장 및 재사용
* 여러 모델의 예측 결과를 활용한 앙상블 실험

## 1. 로그 마스킹 전처리

### 📄 담당 파일

`보안_로그_마스킹_정규화.py`

로그 데이터에 포함된 다양한 가변 정보를 정규표현식으로 탐지하고, 지정된 토큰으로 치환하는 전처리 함수를 구현했습니다.

### 마스킹 대상

|         대상         |     치환 토큰    |
| :----------------: | :----------: |
|        IP 주소       |    `<IP>`    |
|         날짜         |   `<DATE>`   |
|         시간         |   `<TIME>`   |
|        날짜·시간       | `<DATETIME>` |
|        포트 번호       |   `<PORT>`   |
|        일반 숫자       |    `<NUM>`   |
|      16진수 문자열      |    `<HEX>`   |
| 시리얼 번호 및 특정 식별자 패턴 |    `<SN>`    |

### 단계별 마스킹 실험

마스킹을 적용하지 않은 원본 로그를 기준으로 개별 마스킹 및 전체 마스킹을 단계별로 실험했습니다.

```text
0단계 : Baseline (마스킹 없음)
1단계 : IP 주소 마스킹
2단계 : 날짜 마스킹
3단계 : 시간 마스킹
4단계 : 날짜·시간 마스킹
5단계 : 포트 번호 마스킹
6단계 : 일반 숫자 마스킹
7단계 : 16진수 문자열 마스킹
8단계 : 시리얼 번호 패턴 마스킹
9단계 : 전체 토큰 종합 마스킹
```

각 단계에서 동일한 데이터 분할 기준을 적용하고, 전처리 방식에 따른 분류 성능을 비교할 수 있도록 구성했습니다.

### 구현한 주요 내용

* 정규표현식을 활용한 로그 내 패턴 탐지
* 로그의 날짜·시간 및 네트워크 정보 마스킹
* 마스킹 단계별 실험을 위한 함수화
* 원본 데이터 보존을 위한 복사 후 전처리
* 마스킹 방식별 성능 비교를 위한 Ablation Study
* 마스킹 토큰이 하나의 의미 있는 특징으로 처리되도록 텍스트 벡터화 패턴 설정

## 2. 텍스트 특징 추출 및 XGBoost 분류

마스킹된 로그 텍스트를 머신러닝 모델이 학습할 수 있도록 텍스트 특징으로 변환했습니다.

### 처리 과정

```text
로그 텍스트
    │
    ▼
CountVectorizer
    │
    ▼
TF-IDF 변환
    │
    ▼
XGBoost 분류 모델
    │
    ▼
위험도 예측
```

### 적용한 설정

* `CountVectorizer`를 활용한 텍스트 특징 추출
* 1-gram 및 2-gram 특징 활용
* 최대 특징 수 제한
* 최소·최대 문서 빈도 설정
* `<IP>`, `<DATE>` 등의 마스킹 토큰을 보존하는 토큰 패턴 적용
* `TfidfTransformer`를 활용한 TF-IDF 변환
* XGBoost 다중 분류 모델 학습
* 검증 데이터에 대한 Macro F1 평가

### 성능 평가

클래스별 성능을 균형 있게 확인하기 위해 **Macro F1 Score**를 평가 지표로 사용했습니다.

마스킹 단계별로 모델을 학습하고 검증 성능을 비교하여 어떤 전처리 방식이 분류에 적합한지 확인할 수 있도록 구성했습니다.

## 3. 딥러닝 기반 로그 분류

프로젝트에서는 텍스트 분류를 위한 여러 딥러닝 모델을 학습하고 결과를 비교했습니다.

### 실험 모델

|        모델        | 목적                     |
| :--------------: | :--------------------- |
|    Pure 1D-CNN   | 로그의 지역적인 토큰 패턴 학습      |
|       LSTM       | 로그 토큰의 순차적인 정보 학습      |
|   CNN + BiLSTM   | 지역적인 특징과 순차적 특징을 함께 학습 |
| Embedding + LSTM | 임베딩된 로그 토큰의 순차적 특징 학습  |

실험 결과는 `260622_발표준비/` 폴더의 모델 비교 및 성능 시각화 자료를 통해 정리했습니다.

## 💡 프로젝트를 통해 학습한 내용

### 1. 텍스트 전처리의 중요성

보안 로그는 다양한 형식의 정보가 혼합되어 있기 때문에, 단순히 텍스트를 벡터화하는 것뿐만 아니라 로그에 포함된 가변 정보를 어떻게 처리할 것인지가 중요하다는 점을 학습했습니다.

정규표현식을 활용하여 로그 내 패턴을 탐지하고, 마스킹 전처리 방식에 따른 분류 성능을 비교하는 과정을 경험했습니다.

### 2. 전처리와 모델 성능의 관계

동일한 분류 모델을 사용하더라도 입력 데이터의 전처리 방식에 따라 결과가 달라질 수 있다는 점을 확인했습니다.

마스킹 대상과 적용 순서를 조절하는 Ablation Study를 통해 전처리 방법을 실험적으로 비교하는 과정을 수행했습니다.

### 3. 머신러닝과 딥러닝 모델 비교

TF-IDF 기반 머신러닝 모델과 CNN·LSTM 계열의 딥러닝 모델을 비교하며, 텍스트 데이터에 적용되는 특징 추출 방식과 모델 구조의 차이를 학습했습니다.

### 4. 모델 재사용을 위한 저장 구조

학습한 모델과 전처리 객체를 파일로 저장하고 불러오는 과정을 구성하면서, 모델 학습 이후에도 동일한 전처리 및 예측 과정을 재사용할 수 있도록 관리하는 방법을 경험했습니다.

### 5. 앙상블을 통한 성능 비교

서로 다른 모델의 예측 결과를 결합하는 앙상블 실험을 통해 단일 모델과 복수 모델을 활용하는 방식의 차이를 비교했습니다.
