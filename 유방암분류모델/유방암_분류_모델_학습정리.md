# 🩺 유방암 진단 분류 모델 (Breast Cancer Classification)

## 📌 1. 프로젝트 개요
- **유형:** 개인 학습 프로젝트
- **주제:** 위스콘신 유방암 데이터셋(Breast Cancer Wisconsin Dataset)을 활용한 악성(Malignant) / 양성(Benign) 종양 이진 분류 모델 구현
- **목적:** 
  - 머신러닝 데이터 전처리 및 탐색적 데이터 분석(EDA) 흐름 익히기
  - 다양한 분류 알고리즘(Logistic Regression, SVM, Random Forest 등) 비교 분석
  - 의료 데이터 특성에 맞는 평가 지표(Recall/Sensitivity)의 중요성 이해

---

## 🛠️ 기술 스택 및 환경
- **Language:** Python
- **Environment:** Jupyter Notebook
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn

---

## 📊 2. 데이터셋 및 전처리

### 데이터셋 정보
- **출처:** Scikit-learn Built-in Dataset (`load_breast_cancer`)
- **샘플 수:** 569개
- **특징(Feature) 수:** 30개 (세포 핵의 반지름, 질감, 둘레, 면적, 매끄러움 등)
- **타겟(Target):** 
  - `0`: 악성 (Malignant)
  - `1`: 양성 (Benign)

### 주요 전처리 과정
1. **결측치 및 이상치 확인:** 데이터 무결성 검증
2. **특징 스케일링 (Feature Scaling):**
   - 특성 간 단위 차이를 맞추기 위해 `StandardScaler` 적용 (SVM, Logistic Regression 성능 최적화)
3. **데이터 분할 (Train/Test Split):**
   - `train_test_split`을 이용해 8:2 비율로 분할 (`stratify` 옵션을 통해 클래스 비율 유지)

---

## 🔬 3. 사용한 모델 및 실험

다양한 분류 알고리즘을 적용하여 성능을 비교 실험했습니다.

1. **Logistic Regression:** 선형 경계를 통한 기초 이진 분류 모델 구축
2. **K-Nearest Neighbors (KNN):** 이웃 수($K$) 변화에 따른 정밀도/재현율 변화 관찰
3. **Support Vector Machine (SVM):** RBF 커널을 적용하여 비선형 경계 학습
4. **Decision Tree & Random Forest:** 트리 기반 모델을 통한 특성 중요도(Feature Importance) 파악

---

## 📈 4. 모델 평가 및 결과

> 💡 **의료 데이터에서의 핵심 지표:** 실제 악성(Malignant) 환자를 양성으로 잘못 판정하는 위험을 줄여야 하므로 **재현율(Recall)**을 최우선 평가 지표로 설정했습니다.

| 모델 (Model) | Accuracy | Precision | Recall (재현율) | F1-Score |
| :--- | :---: | :---: | :---: | :---: |
| Logistic Regression | 0.97 | 0.96 | 0.98 | 0.97 |
| KNN (K=5) | 0.95 | 0.94 | 0.96 | 0.95 |
| **SVM (Standardized)** | **0.98** | **0.97** | **0.99** | **0.98** |
| Random Forest | 0.96 | 0.96 | 0.97 | 0.96 |

- **최종 선정 모델:** **SVM (Support Vector Machine)**
  - `StandardScaler` 적용 후 SVM 모델이 가장 높은 Accuracy(98%)와 Recall(99%)을 기록함.

## 💡 5. 핵심 배운 점 & 인사이트

1. **특성 스케일링의 중요성:**
   - 거리 기반 알고리즘(KNN, SVM)과 구배 강하법 기반 모델(Logistic Regression)은 특성 스케일링 적용 여부에 따라 성능 차이가 크게 나타남을 확인했습니다.
2. **의료 분류 모델의 평가지표 설정:**
   - 단순 Accuracy(정확도)보다 FN(False Negative, 악성을 양성으로 오진)을 줄이는 **Recall(재현율)** 관점이 진단 모델에서 왜 치명적인지 실습을 통해 체득했습니다.
3. **특성 중요도 파악:**
   - Random Forest의 `feature_importances_` 분석을 통해 `worst concave points`, `worst perimeter` 등의 특성이 종양 악성 여부 판단에 가장 큰 영향을 미친다는 점을 확인했습니다.
