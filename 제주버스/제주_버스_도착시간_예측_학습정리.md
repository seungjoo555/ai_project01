# 🚌 제주 버스 도착시간 예측 (학습 파이프라인 실습)

## 📌 1. 학습 개요
- **성격:** 머신러닝 데이터 분석 및 예측 파이프라인 학습 실습
- **주제:** 제주도 버스 운행 데이터를 활용하여 버스 정류장 간 이동 및 도착 시간을 예측하는 회귀(Regression) 모델 구축
- **학습 목표:**
  - 시계열 및 공간 요소가 포함된 정형 데이터(Tabular Data)의 전처리 및 특성 공학(Feature Engineering) 흐름 습득
  - 다양한 머신러닝 회귀 모델(Random Forest, XGBoost, LightGBM 등)의 구조 이해 및 성능 비교
  - 교차 검증(Cross Validation)과 회귀 평가 지표(RMSE)를 통한 모델 검증 프로세스 체득

## 🔄 2. 단계별 학습 파이프라인 (Learning Pipeline)

### Step 1. 데이터 탐색 (EDA) & 데이터 이해
- 버스 노선(`route_id`), 정류장(`bus_stop`), 승하차 인원, 시간대, 위치(위도/경도) 등 컬럼 구조 분석
- Target Variable(버스 정류장 간 이동 시간)의 분포 및 이상치 확인

### Step 2. 데이터 전처리 및 특성 공학 (Feature Engineering)
- **시간 특성 추출:** 날짜/시간 데이터에서 요일, 출퇴근 시간대 구분, 평일/주말 여부 등의 파생 변수 생성
- **공간 및 노선 특성:** 정류장 간 거리 계산 및 노선별/정류장별 평균 소요 시간 집계(Aggregation)
- **범주형 변수 인코딩:** `LabelEncoder` 및 `One-Hot Encoding`을 통한 수치화
- **데이터 정리:** 모델 학습에 불필요한 고유 ID 및 중복 특성 제거

### Step 3. 모델 적용 및 비교 (Models Used)
회귀 알고리즘을 단계별로 적용하며 성능 변화를 관찰했습니다.

1. **Linear Regression & Decision Tree:** 기본 성능 측정을 위한 베이스라인(Baseline) 모델 구축
2. **Random Forest Regressor:** 배깅(Bagging) 기반 앙상블 알고리즘을 통한 과적합 방지 실습
3. **XGBoost & LightGBM:** 
   - 부스팅(Boosting) 계열 알고리즘을 활용한 정형 데이터 예측 성능 극대화
   - 대용량 데이터에서 `LightGBM`의 빠른 학습 속도와 우수한 예측 성능 체감

### Step 4. 모델 평가 및 검증
- **평가 지표:** `RMSE (Root Mean Squared Error)`, `MAE (Mean Absolute Error)`
- **K-Fold Cross Validation:** 데이터 편향을 방지하고 모델의 일반화 성능을 검증하기 위해 5-Fold 교차 검증 수행

## 💡 3. 습득한 핵심 기술 및 역량 (Key Learnings)

1. **도메인 특성을 반영한 특성 공학(Feature Engineering)**
   - 단순히 기존 컬럼을 사용하는 것을 넘어 시간대, 정류장 위치 등의 도메인 지식을 활용해 파생 변수를 직접 생성하고 모델 성능을 개선하는 법을 습득했습니다.
2. **Gradient Boosting 계열 모델(LightGBM, XGBoost)의 이해**
   - 정형 데이터 분석에서 널리 쓰이는 트리 기반 앙상블 모델의 원리를 이해하고, 주요 하이퍼파라미터가 모델 예측력 및 오버피팅에 미치는 영향을 파악했습니다.
3. **End-to-End 머신러닝 파이프라인 구축 능력**
   - [데이터 EDA ➡️ 전처리 ➡️ 특성 공학 ➡️ 모델 학습 ➡️ 교차 검증 ➡️ 성능 평가]로 이어지는 머신러닝 분석의 표준적 흐름을 체득했습니다.
